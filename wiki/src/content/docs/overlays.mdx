## From layers to one effective profile

The public profile defines a reusable base. A repository-specific overlay changes only what it needs. Later mappings merge recursively, while sequences and scalar values replace earlier values.

```text
public .ai core + project overlay → effective profile → provider adapters
```

The composition mechanism already lives in [tools/render_profile.py](https://github.com/trvny/.ai/blob/main/tools/render_profile.py), and its contract lives in [docs/profile-reference.md](https://github.com/trvny/.ai/blob/main/docs/profile-reference.md). Those remain the source of truth.

### Next experiment
